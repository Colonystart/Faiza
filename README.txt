FAIZA BIRTHDAY WEBSITE

1. Keep index.html and the assets folder together.
2. Open index.html in a browser to preview.
3. To publish it free, upload the whole folder to a static hosting service such as GitHub Pages or Netlify.
4. To personalise the letter, edit the text inside <div class="message"> in index.html.
5. The three photos are in assets/ and are used as the fading background.

This is a static website; no login, database, or paid service is required.
